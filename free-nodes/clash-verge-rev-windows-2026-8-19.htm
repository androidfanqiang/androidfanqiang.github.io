一、什么是Shadowrocket？

Shadowrocket 是一款专为 iOS 平台打造的网络代理工具，功能强大且配置灵活，主要用于设置代理、实现加密流量转发，从而突破地域或网络限制，同时保障用户的上网安全与隐私。

其核心特点如下：

  • 协议支持广泛：支持 Shadowsocks、Vmess、Trojan、HTTP、HTTPS、SOCKS5 等多种协议；

  • 规则灵活：可自定义规则分流，按域名/IP/应用进行流量分类管理；

  • 流量统计详细：实时监控上传/下载速度，帮助用户精确了解网络使用情况；

  • IPv6支持完善：适配现代网络环境；

  • 兼容订阅功能：一键导入节点，动态更新配置文件，极大方便用户维护节点列表。

对于追求隐私、自由、性能的iOS用户来说，Shadowrocket几乎是必不可少的工具。

三、Shadowrocket的基础配置教程

1. 添加代理节点

Shadowrocket支持手动输入节点或通过订阅链接一键导入节点列表。推荐使用订阅链接方式，便于统一管理与自动更新。

方法一：手动添加

  • 打开Shadowrocket；

  • 点击右上角“+”图标 → 选择节点类型（如Shadowsocks、Vmess等）；

  • 填入服务器信息：地址、端口、密码、加密方式等；

  • 保存后即可看到节点出现在列表中。

方法二：使用订阅链接导入

  • 获取订阅地址（如Clash牧场或Telegram群中分享的）；

  • 打开Shadowrocket → 点击“配置” → 添加配置 → 输入订阅URL；

  • 命名后保存，并点击右上角刷新按钮同步节点。

多数节点提供商都会提供兼容Shadowrocket的专用链接。

2. 设置规则分流（可选）

Shadowrocket支持多种代理模式：

  • 全局代理：所有流量均通过代理；

  • 规则模式：按域名/IP或国家归属进行智能分流；

  • 绕过大陆地址：国内流量直连，境外流量代理。

你可以通过添加公共规则集（如ACL4SSR）来自动化管理：

  • 打开“配置”；

  • 点击“规则” → “远程规则”；

  • 添加远程规则地址（例如GitHub上的规则订阅）；

  • 启用该规则配置。

3. 启用代理

  • 配置完成后，返回主界面；

  • 点击右上角开关按钮，首次启用会提示添加VPN配置；

  • 点击“允许”，输入设备密码，授权后将自动建立VPN隧道；

  • 状态栏显示VPN图标，即表示代理已启动成功。

四、使用技巧与进阶配置

✅ 配合第三方DNS使用

推荐搭配 DoH（DNS over HTTPS）服务，如Cloudflare的 1.1.1.1，增强域名解析隐私性与准确性。

路径：设置 → DNS → 添加 → 选择 DoH → 输入地址。

✅ 绑定特定应用使用代理

可开启“分应用代理”模式，仅对部分App启用代理，如YouTube、Telegram等，节省流量并提高效率。

路径：设置 → 应用规则 → 添加 → 选择App → 指定代理方式。

✅ 实时测速与节点切换

长按某个节点可进行测速，数值越小表示连接延迟越低；推荐根据延迟情况选择速度最佳节点。

✅ 多配置切换

支持保存多个配置文件，适用于不同场景（如工作/娱乐/旅行），在主界面一键切换。

FAQ

WinXray 如何导入订阅？
在 WinXray 界面中点击“导入订阅”选项，将机场提供的订阅链接粘贴进去。点击更新后，WinXray 会自动下载节点配置并生成列表，用户可手动选择或自动切换延迟最低的节点使用。
Hiddify Next 是什么？
Hiddify Next 是基于 sing-box 的多协议代理客户端，适用于 Android、Windows 等平台。它整合了 Vless、VMess、Trojan、Hysteria 等协议，支持自动测速和订阅转换，是移动端非常流行的代理工具。
如何为 Vmess 节点生成安全的 UUID？
UUID 应使用标准的 128 位格式，可使用系统命令如 `uuidgen` 或在线 UUID 生成器生成随机、唯一的 ID；不要使用默认或弱随机值，定期更换以降低被滥用或泄露的风险。
Sing-box 如何兼容 Clash 的配置文件？
Sing-box 支持 Clash 规则格式的解析，用户可直接导入 Clash 的 YAML 配置文件进行使用。虽然部分高级参数需要调整，但大多数分流和策略配置都能自动识别，便于迁移。
SSR 的混淆方式如何选择最合适？
根据网络环境选择适合的混淆方式，如 tls1.2_ticket_auth 模拟 HTTPS 流量，可隐藏真实特征。结合协议插件使用，可以提高抗封锁能力和节点可用性。
V2Ray 如何通过策略组优化访问速度？
策略组允许用户将节点按延迟、地域或用途分组。结合路由规则，V2Ray 会自动选择最优节点处理流量，提升访问速度并降低延迟，尤其在访问海外网站时效果明显。
Trojan-Go 的多路复用（mux）如何开启？
Trojan-Go 在配置文件中通过启用 mux 参数即可实现多路复用。此功能允许多个连接共享同一隧道，减少握手延迟并提升整体传输效率，尤其在移动网络中表现出色。
Hiddify Next 如何设置用户带宽与流量配额？
管理员可为每个用户单独设置带宽和流量上限。超出限制时，可自动降速或阻止访问，确保服务器资源合理分配，避免单用户占用过多带宽，提高整体网络公平性和效率。
Shadowrocket 可以在哪些平台使用？
Shadowrocket 是一款 iOS 平台专用代理客户端，支持多种协议如 Vmess、Shadowsocks、Trojan 等。用户可通过导入订阅链接快速配置节点，配合规则分流功能实现精准网络代理。由于其强大功能，它是 iPhone 用户常用的科学上网工具。
SSR 如何配置混淆以应对封锁升级？
选择合适的混淆方式，如 tls1.2_ticket_auth，可模拟正常 HTTPS 流量。合理搭配协议和混淆参数，可有效降低被 DPI 检测和封锁的风险，提高节点长期稳定性。
